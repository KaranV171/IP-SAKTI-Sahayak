# IP Sakti Sahayak

IP Sakti Sahayak is a platform designed to assist users with intellectual property (IP) related services, such as patent guidance, trademark support, legal information, and documentation assistance. The system aims to simplify the process of understanding and managing intellectual property rights.

## Project Overview

This project helps users:
- Understand different types of intellectual property
- Get guidance on IP registration and protection
- Manage IP-related documentation and workflows
- Access information in a simple and user-friendly interface

## Features

- User-friendly dashboard
- IP information and guidance
- Patent/trademark help section
- Document management
- Secure user authentication
- Admin panel for managing content and records
- Responsive design for web and mobile screens

## Tech Stack

- Frontend: HTML, CSS, JavaScript / React
- Backend: Node.js / Express / Python Flask / Django
- Database: MongoDB / MySQL / PostgreSQL
- Authentication: JWT / Firebase / Session-based auth
- Deployment: Vercel / Netlify / Render / AWS
